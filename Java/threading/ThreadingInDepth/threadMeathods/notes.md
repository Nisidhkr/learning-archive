# Thread Methods

1. **start()** - Initiates the overridden `run()` method in a new thread and begins thread execution

2. **run()** - Contains the code that executes when the thread is running

3. **sleep()** - Pauses the current thread for a specified duration in milliseconds

4. **join()** - Waits for another thread to complete its execution before the current thread continues

5. **setPriority()** - Sets the priority level of a thread (useful when multiple threads are running) to determine which thread gets more CPU time
